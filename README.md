## 🧭 What you'll find here

**Network services**
- Directory services and authentication
- DNS, DHCP and routing
- Web servers, digital certificates and mail servers
- VPNs, firewalls and access control

**Security and high availability**
- OSINT and DNS research
- Traffic and protocol analysis with Wireshark
- Incident response simulations (ransomware, phishing)
- Backup strategies, redundancy and disaster recovery
